## ความน่าเชื่อถือของแต่ละพาเลต

- `official` — ผู้ผลิตหรือตัวเกมเผยแพร่ค่าเหล่านี้เอง และค่าของเราตรงกัน
- `measured` — วัดจากสื่อของผู้ผลิตเองด้วยวิธีที่บันทึกไว้
- `cross-checked` — เทียบหลายแหล่งที่เป็นอิสระต่อกัน ตัดสินข้อขัดแย้งด้วยกฎที่เขียนไว้
- `community` — ผู้ที่ชื่นชอบเก็บค่าจากลูกปัดหรือภาพถ่ายจริง ยังไม่ได้ตรวจสอบโดยอิสระ
- `approximate` — ตรวจรหัสและชื่อแล้ว สียังไม่ได้ปรับเทียบ
- `generated` — ไม่ใช่สายผลิตภัณฑ์

ไม่มีหน้าจอใดแสดงลูกปัดจริงได้ตรงเป๊ะ ผิว แสง และจอภาพล้วนเปลี่ยนสี ใช้ค่า Hex เพื่อเลือกและเปรียบเทียบ แล้วซื้อตามรหัส

## วิธีใช้

### ดาวน์โหลดหรือลิงก์ไฟล์

ทุกพาเลตมีไฟล์ JSON และ CSV ลิงก์ได้โดยตรงจาก CDN:

```
https://cdn.jsdelivr.net/gh/makebead/craft-color-codes@main/data/json/dmc-floss.json
https://cdn.jsdelivr.net/npm/craft-color-codes@1/data/csv/miyuki-delica.csv
```

### JavaScript

ค้นหารหัส หาสีที่ใกล้ที่สุด แปลงระหว่างแบรนด์ ไม่มี dependency

```sh
npm install craft-color-codes
```

```js
import { getColor, nearest, convert } from 'craft-color-codes';

getColor('delica', 'DB10'); // ใช้ได้ทั้ง "DB10" "DB-010" และ "10"
// → { code: 'DB0010', name: 'Opaque Black', hex: '#131313' }

nearest('#E8A0B0', 'dmc', { limit: 3 }); // ไหม DMC ที่ใกล้สีที่สุด
// → [{ code: '3354', name: 'Dusty Rose Light', hex: '#E4A6AC', deltaE: 3.62 }, …]

convert('perler', 'P38', 'hama'); // Perler P38 → Hama
// → { from: { code: 'P38', name: 'Magenta', … }, matches: [{ code: 'H32', name: 'Neon Fuchsia', hex: '#FF208D', deltaE: 4.81 }, …] }
```

### เซิร์ฟเวอร์ MCP (Claude, Cursor, VS Code…)

ให้ผู้ช่วย AI ใช้พาเลตเป็นเครื่องมือ เพื่อให้ตอบคำถามอย่าง “Perler P38 ตรงกับ Hama เบอร์อะไร” หรือ “ไหม DMC สีไหนใกล้ #E8A0B0 ที่สุด” จากข้อมูลจริง ไม่ใช่จากความจำ

Claude Code:

```sh
claude mcp add craft-color-codes -- npx -y craft-color-codes
```

ไคลเอนต์อื่น (Claude Desktop, Cursor, VS Code):

```json
{
  "mcpServers": {
    "craft-color-codes": {
      "command": "npx",
      "args": [
        "-y",
        "craft-color-codes"
      ]
    }
  }
}
```

- `list_palettes` — ทุกพาเลตพร้อมสถานะ
- `get_color` — สีหนึ่งสีจากรหัส เขียนแบบไหนก็ได้
- `find_closest` — สีที่ใกล้ค่า Hex ที่สุด เรียงตาม CIEDE2000
- `convert_color` — รหัสของแบรนด์หนึ่ง → สีที่ใกล้เคียงในอีกแบรนด์
- `search_colors` — ค้นหาด้วยชื่อสีหรือรหัส

## รูปแบบข้อมูล

ไฟล์พาเลตแต่ละไฟล์มีคำอธิบาย แหล่งที่มา และสัญญาอนุญาตของตัวเอง:

```jsonc
{
  "id": "miyuki-delica",
  "brand": "Miyuki",
  "product": "Miyuki Delica 11/0 (DB)",
  "count": 1288,
  "status": "measured",
  "notes": "…", "sources": [ … ], "license": "CC-BY-4.0",
  "colors": [
    {"code":"DB0010","name":"Opaque Black","hex":"#131313","rgb":[19,19,19],"glass":"opaque"},
    …
  ]
}
```

- `code` — ตามที่พิมพ์บนถุง หลอด ไจ หรือชิ้นส่วน
- `hex` — `#RRGGBB` ตัวพิมพ์ใหญ่ และ `rgb` เป็น `[r, g, b]`
- `discontinued` — เป็น `true` เฉพาะสีที่เลิกผลิต (Miyuki Delica)
- ฟิลด์เฉพาะพาเลต: `sku` (รหัสสินค้า Perler), `glass` (ชนิดแก้ว Delica), `group` `block` `survival` (บล็อก Minecraft), `base` `shade` `buildable` (สีแผนที่ Minecraft)

CSV มีสีชุดเดียวกัน หนึ่งสีต่อหนึ่งแถว:

```csv
code,name,hex,r,g,b,discontinued,glass
DB0010,Opaque Black,#131313,19,19,19,false,opaque
```
