## 팔레트별 신뢰도

- `official` — 제조사나 게임이 직접 공개한 값이며 우리 값과 일치
- `measured` — 제조사 자료에서 기록된 방법으로 측정
- `cross-checked` — 독립된 여러 출처를 비교하고, 충돌은 정해진 규칙으로 판정
- `community` — 취미가들이 실물 비즈나 사진에서 추출, 독립 검증 없음
- `approximate` — 코드와 이름은 확인, 색은 아직 보정 전
- `generated` — 제품 라인이 아님

실물 비즈를 정확히 보여 주는 화면은 없습니다. 질감·조명·모니터에 따라 달라집니다. Hex는 고르고 비교할 때 쓰고, 살 때는 코드로 사세요.

## 사용법

### 파일 다운로드 또는 링크

모든 팔레트는 JSON과 CSV 파일로 제공됩니다. CDN에서 바로 링크하세요:

```
https://cdn.jsdelivr.net/gh/makebead/craft-color-codes@main/data/json/dmc-floss.json
https://cdn.jsdelivr.net/npm/craft-color-codes@1/data/csv/miyuki-delica.csv
```

### JavaScript

코드 조회, 가장 가까운 색 찾기, 브랜드 간 변환. 의존성 없음.

```sh
npm install craft-color-codes
```

```js
import { getColor, nearest, convert } from 'craft-color-codes';

getColor('delica', 'DB10'); // "DB10", "DB-010", "10" 모두 가능
// → { code: 'DB0010', name: 'Opaque Black', hex: '#131313' }

nearest('#E8A0B0', 'dmc', { limit: 3 }); // 어떤 색에 가장 가까운 DMC 실
// → [{ code: '3354', name: 'Dusty Rose Light', hex: '#E4A6AC', deltaE: 3.62 }, …]

convert('perler', 'P38', 'hama'); // Perler P38 → Hama
// → { from: { code: 'P38', name: 'Magenta', … }, matches: [{ code: 'H32', name: 'Neon Fuchsia', hex: '#FF208D', deltaE: 4.81 }, …] }
```

### MCP 서버 (Claude, Cursor, VS Code 등)

AI 어시스턴트에게 팔레트를 도구로 줄 수 있습니다. "Perler P38은 Hama로 몇 번?", "#E8A0B0에 가장 가까운 DMC 실은?"에 기억이 아니라 데이터로 답하게 됩니다.

Claude Code:

```sh
claude mcp add craft-color-codes -- npx -y craft-color-codes
```

다른 클라이언트 (Claude Desktop, Cursor, VS Code):

```json
{
  "mcpServers": {
    "craft-color-codes": {
      "command": "npx",
      "args": [
        "-y",
        "craft-color-codes"
      ]
    }
  }
}
```

- `list_palettes` — 모든 팔레트와 상태
- `get_color` — 코드로 한 가지 색 조회 (여러 표기 방식 지원)
- `find_closest` — Hex 색에 가까운 색을 CIEDE2000 순으로
- `convert_color` — 한 브랜드의 코드 → 다른 브랜드의 가까운 색
- `search_colors` — 색 이름이나 코드로 검색

## 데이터 형식

각 팔레트 파일에는 설명·출처·라이선스가 들어 있습니다:

```jsonc
{
  "id": "miyuki-delica",
  "brand": "Miyuki",
  "product": "Miyuki Delica 11/0 (DB)",
  "count": 1288,
  "status": "measured",
  "notes": "…", "sources": [ … ], "license": "CC-BY-4.0",
  "colors": [
    {"code":"DB0010","name":"Opaque Black","hex":"#131313","rgb":[19,19,19],"glass":"opaque"},
    …
  ]
}
```

- `code` — 봉지·튜브·타래·부품에 인쇄된 번호
- `hex` — `#RRGGBB` 대문자, `rgb`는 `[r, g, b]`
- `discontinued` — 단종된 색에만 `true` (Miyuki Delica)
- 팔레트별 필드: `sku`(Perler 품번), `glass`(Delica 유리 종류), `group`·`block`·`survival`(마인크래프트 블록), `base`·`shade`·`buildable`(마인크래프트 지도 색)

CSV에는 같은 색이 한 줄에 하나씩 들어 있습니다:

```csv
code,name,hex,r,g,b,discontinued,glass
DB0010,Opaque Black,#131313,19,19,19,false,opaque
```

## 숫자의 출처

각 팔레트의 출처, 방법, 알려진 약점은 [SOURCES.md](../SOURCES.md)(영어)와 파일의 `notes`에 있습니다. 검증으로 찾은 예 두 가지: DMC 309(Rose Dark)는 널리 쓰이는 원본 데이터에서 회갈색이지만 여기서는 빨간색입니다. Delica는 MakeBead의 예전 39색 데이터가 불투명 초록인 DB0724를 빨간색으로 그리고 있어 Miyuki 공식 사진으로 다시 만들었습니다.

## 틀린 색을 발견했다면

팔레트, 코드, 실제로 보이는 색을 적어 Issue를 열어 주세요. 가능하면 흰 종이 옆에 둔 비즈·실·블록을 낮에 찍은 사진을 함께 올려 주세요. 수정은 먼저 MakeBead에 반영되고 여기에 다시 게시됩니다.

→ [틀린 색 신고하기](https://github.com/makebead/craft-color-codes/issues/new?template=wrong-color.yml)
